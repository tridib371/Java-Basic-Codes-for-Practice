# ☕ Java Basic Codes for Practice

Welcome to **Java Basic Codes for Practice**, a collection of essential **Java programs** and **theory slides** designed to strengthen your understanding of the **fundamentals of Java programming**.  
This repository serves as a complete reference for beginners learning Java through **hands-on coding and conceptual study**.

---

## 📘 Overview

This repository contains **basic Java programs** along with **theoretical explanations and example slides** to help learners build a solid foundation in Java.  
It’s perfect for students who are starting their journey with **Object-Oriented Programming** and want to practice real code examples side by side with concise theory.

Key topics covered include:
- ✅ Variables, Data Types, and Operators  
- ✅ Conditional Statements (if, else, switch)  
- ✅ Loops (for, while, do-while)  
- ✅ Arrays and Strings  
- ✅ Methods and Classes  
- ✅ Basic OOP Concepts (Encapsulation, Inheritance, Polymorphism)  

---

## 🧩 Features

- 📜 Collection of simple and well-documented Java programs  
- 💡 Includes **theory slides** explaining each topic  
- 🔍 Step-by-step examples with expected outputs  
- ⚙️ Beginner-friendly and easy to compile/run  
- 🧱 Built and tested using **Notepad++** and **Java JDK 17+**
